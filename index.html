Keahlian

Cara Saya Bekerja

Alat yang benar benar saya pakai di proyek di atas, dikelompokkan menurut tahap pekerjaannya. Bukan daftar kata kunci.

Mengambil dan membersihkan data

  • Python dengan pandas dan NumPy. Dipakai di semua proyek, dari membersihkan 65.437 baris survei developer sampai menyusun katalog 9.600 gempa.
  • SQL dan Google BigQuery. Query analisis dan join tabel, termasuk 14 query terdokumentasi pada proyek inflasi.
  • Excel dan Google Sheets. Pembersihan awal, pivot, dan pemeriksaan silang angka sebelum masuk ke Python.

Menganalisis dan memvisualkan

  • Exploratory data analysis dan descriptive statistics. Customer segmentation pada churn, perbandingan antar provinsi, dan pembacaan tren tujuh tahun.
  • Power BI. Star schema, DAX measures, dan dashboard empat halaman yang dibangun untuk setiap proyek portofolio.
  • Matplotlib dan Seaborn. Grafik publikasi yang dipakai di presentasi dan modul setiap proyek.

Menyampaikan hasil

  • Presentasi dan modul tertulis. Setiap proyek ditutup dengan deck dan modul PDF yang menjelaskan temuan dalam bahasa yang bisa diikuti nonteknis.
  • Git dan GitHub. Kode, data bersih, dan dokumentasi setiap proyek tersimpan rapi per repositori.

Sedang saya pelajari

Jalur belajar saya mengarah ke Data Science: machine learning dengan scikit-learn, network analysis, recommender systems, dan pattern mining. Materi ini datang dari program More Applied Data Science with Python, University of Michigan, dan Data Science Foundations, University of London, yang keduanya sudah saya selesaikan sebagai coursework.
